# Network Graph Analysis

This project demonstrates the application of graph theory to analyze relationships and routing within a network structure.

## 📝 Overview
Using the NetworkX library, this project constructs a synthetic network graph to analyze node importance and connectivity.

## 🚀 Features
- **Graph Creation:** Generates a network graph with a defined number of nodes and edges.
- **Centrality Metrics:** 
  - Calculates **Degree Centrality** to find the most connected nodes.
  - Calculates **Betweenness Centrality** to identify bottleneck nodes or critical bridges in the network.
- **Path Analysis:** Computes the shortest path between a source node and a target node.
- **Visualization:** Renders a visual representation of the network graph.

## 🛠️ Tech Stack
- Python
- NetworkX
- Matplotlib

## 🔧 How to Run
```bash
python pz.py
```
