# Energy Cost Distributions

This project explores statistical distributions and their practical applications in modeling continuous variables like energy costs.

## 📝 Overview
The project uses statistical tools to generate, analyze, and visualize energy cost data following normal and exponential probability distributions.

## 🚀 Features
- **Data Generation:** Creates synthetic datasets representing energy costs using `scipy.stats`.
- **Statistical Analysis:** Computes key descriptive statistics, including mean, variance, and median for both distribution types.
- **Data Visualization:** Plots histograms of the generated data overlaid with theoretical Probability Density Functions (PDF).
- **Object-Oriented Design:** Implemented using a clean object-oriented approach (`EnergyCostAnalyzer` class).

## 🛠️ Tech Stack
- Python
- SciPy (`scipy.stats`)
- NumPy
- Matplotlib

## 🔧 How to Run
```bash
python pz.py
```
