# ML Regression Models Comparison

This project focuses on applying machine learning techniques to predictive modeling using regression algorithms.

## 📝 Overview
The primary goal is to train, evaluate, and compare two different tree-based regression models to understand their predictive capabilities and accuracy on a given dataset.

## 🚀 Features
- **Model Training:** Trains both a `RandomForestRegressor` and a `DecisionTreeRegressor`.
- **Model Evaluation:** Evaluates the models on a test dataset using standard regression metrics:
  - Mean Squared Error (MSE)
  - R² Score (Coefficient of Determination)
- **Comparison:** Contrasts the performance of a single decision tree against an ensemble method (Random Forest).

## 🛠️ Tech Stack
- Python
- Scikit-learn (sklearn)
- Pandas
- NumPy

## 🔧 How to Run
```bash
python pz.py
```
