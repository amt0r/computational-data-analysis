# Data Science Portfolio

This repository contains a collection of practical projects and assignments focusing on various aspects of data analysis, statistical modeling, machine learning, and data visualization. All projects are implemented in Python.

## 📂 Project Structure

The repository is organized into several independent projects. Click on the project names to view their detailed documentation.

### 1. [Smart Home Energy Agent](./smart-home-energy-agent/README.md)
An intelligent simulation agent for managing a private house's energy system. Models solar panels, a wind generator, and a backup gasoline generator with interactive scenario testing.

### 2. [Revenue Time Series Analysis](./revenue-time-series/README.md)
A performance comparison project analyzing large time-series datasets. Compares Pandas rolling methods versus optimized NumPy operations.

### 3. [Energy Cost Distributions](./energy-cost-distributions/README.md)
A statistical analysis project exploring continuous probability distributions (Normal and Exponential) applied to energy costs.

### 4. [Network Graph Analysis](./network-graph-analysis/README.md)
A graph theory and network analysis project exploring degree centrality, betweenness centrality, and shortest-path routing.

### 5. [ML Regression Comparison](./ml-regression-comparison/README.md)
A machine learning project comparing predictive performance between Random Forest and Decision Tree regression models.

### 6. [Light Sensor Analysis](./light-sensor-analysis/README.md)
An IoT sensor data analysis project evaluating smart home lighting efficiency using real-world sensor data.

## 🛠️ General Technologies Used
- **Language:** Python 3.x
- **Data Manipulation:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Data Visualization:** Matplotlib, Seaborn
- **Statistics & Math:** SciPy, NetworkX
